# Data sources

The package reconstructs the operational digital thread from public archives:

- BTS Airline On-Time Performance records provide scheduled and realized flight outcomes.
- IEM ASOS hourly reports provide surface-weather observations at airports and neighboring stations.
- FAA ATCSCC advisory pages provide GDP and GS action records with signature, start, and end times.
- NCEI Storm Events records provide an external weather-event filter.

The repository records acquisition scripts and manifests. Large raw files remain with their public providers.
